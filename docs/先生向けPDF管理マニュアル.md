# 先生向け PDF管理マニュアル

## できること

この画面では、部員が送ったPDFを確認して公開できます。

- 内容を確認する
- 書庫に公開する
- 公開を一時的に止める（非表示）

> **削除は原則として行わないでください。** 間違いに気付いた場合は、まず「非表示」にして管理担当者へ連絡してください。

## 管理画面を開く

1. 次のURLを開きます。  
   `https://wangel-mondai.pages.dev/admin.html`
2. 管理トークンを入力し、「管理画面を開く」を押します。
3. 最初に「承認待ち」のPDFが表示されます。

管理トークンは、他人に見せたり、メールやLINEで転送したりしないでください。操作を終えたら、画面右上の「トークンを消去」を押します。

## PDFを確認して公開する

1. 「承認待ち」から対象のPDFを探します。
2. 行の「PDF表示」ボタンを押して、PDFの内容を確認します。
3. 問題・解答、科目、タイトル、投稿者が適切か確認します。
4. 閉じるときは、PDF画面右上の `×` を押します。
5. 「公開」を押し、確認画面でもう一度「OK」を押します。

公開後、そのPDFは書庫ページに表示されます。

## 公開を一時的に止める

公開内容に誤りがある、または一時的に公開を止めたい場合は、削除ではなく非表示にします。

1. 「公開中」を押します。
2. 対象PDFの「非表示」を押し、確認します。
3. PDFは書庫から見えなくなりますが、データは残ります。

再び公開してよい状態になったら、「非表示」タブから対象PDFを選び、「再公開」を押します。

## 困ったとき

| 状況 | 対応 |
| --- | --- |
| 管理画面を開けない | 管理トークンを確認し、管理担当者に連絡する |
| PDFの内容・タイトルに誤りがある | 公開前なら公開せず、投稿者または管理担当者に連絡する。公開済みなら「非表示」にする |
| 間違えて非表示にした | 「非表示」タブで「再公開」を押す |
| 削除したい | 操作せず、管理担当者に連絡する |

## 操作終了時

画面右上の「トークンを消去」を押してから、ブラウザを閉じてください。
