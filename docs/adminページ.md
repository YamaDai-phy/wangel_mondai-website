# 管理ページの使い方

## 概要

管理ページ（`/admin.html`）では、アップロードされたPDFの状態を確認し、公開・非表示・再公開・削除を行えます。

| 項目 | 内容 |
| --- | --- |
| URL | `https://wangel-mondai.pages.dev/admin.html` |
| 認証 | Workerに設定した `ADMIN_TOKEN` |
| 対象 | D1の `submissions` に登録されているPDF |
| ファイル保管先 | Cloudflare R2（`pdf-storage`） |

管理トークンはブラウザの `sessionStorage` にのみ保存されます。同じタブを開いている間は再入力不要ですが、タブを閉じるか「トークンを消去」を押すと消えます。

## ログイン

1. `/admin.html` を開きます。
2. `ADMIN_TOKEN` と同じ値を「管理トークン」に入力します。
3. 「管理画面を開く」を押します。

一覧を読み込めない場合は、表示されたエラーメッセージを確認してください。

- 「管理者トークンが正しくありません。」: 入力値が `ADMIN_TOKEN` と一致していません。
- 「管理者用の認証がまだ設定されていません。」: Workerに `ADMIN_TOKEN` が設定されていません。
- 通信エラー: Workerの稼働状況、`ALLOWED_ORIGINS`、ネットワークを確認します。

`ADMIN_TOKEN` はWorkerのSecretとして設定します。値そのものはリポジトリや公開ページに保存しないでください。

```powershell
cd worker
npx wrangler secret put ADMIN_TOKEN
```

## 一覧の見方

ログイン直後は「承認待ち」が選ばれます。上部のボタンで表示対象を切り替えられ、各ボタンの数字はその状態の件数です。

| 状態 | 意味 | 管理ページでできること |
| --- | --- | --- |
| 承認待ち（`pending`） | 通常PDFがアップロードされ、まだ公開されていない状態 | PDF確認、公開、削除 |
| 公開中（`published`） | 書庫ページで閲覧できる状態 | PDF確認、非表示、削除 |
| 非表示（`hidden`） | データは残るが書庫ページでは閲覧できない状態 | PDF確認、再公開、削除 |
| すべて | 上記に加え、未完成品・却下済みを含む全状態 | 状態に応じた操作、削除 |

表にはPDF名・元ファイル名・大会情報、種別、投稿者、投稿日時、状態、操作が表示されます。「更新」で最新の一覧を再取得できます。

種別は「自作／過去問」「問題／答え／問題・答え」および科目の組み合わせで表示されます。

## 操作手順

### PDFを確認する

行の「PDF表示」アイコンを押すと、PDFをモーダル内でプレビューできます。確認後は右上の `×` で閉じます。

### 承認待ちのPDFを公開する

1. 「承認待ち」から対象PDFを探し、内容とメタデータを確認します。
2. 「公開」を押します。
3. 確認ダイアログで実行を確定します。

状態が `published` になり、書庫ページのPDF一覧に表示されます。公開日時もこの時点で更新されます。

### 公開を止める（非表示）

1. 「公開中」から対象PDFを探します。
2. 「非表示」を押し、確認します。

PDFと登録情報は保持したまま状態が `hidden` になり、書庫ページの一覧から消えます。

### 再公開する

1. 「非表示」から対象PDFを探します。
2. 「再公開」を押し、確認します。

状態が `published` に戻り、書庫ページに再び表示されます。

### 完全に削除する

1. 対象PDFの内容と状態を確認します。
2. 「削除」を押し、確認ダイアログで実行を確定します。

削除すると、R2上のPDF本体とD1上の登録情報の両方が削除されます。管理ページから元に戻すことはできません。誤削除が心配な場合は、まず「非表示」を使ってください。

## 注意事項

- 「公開」「非表示」「再公開」は、表示されている状態からのみ実行できます。たとえば、公開中のPDFを直接「公開」することはできません。
- 未完成品（`incomplete`）は管理画面で公開できません。アップロード時に発行される確認リンク（`review.html`）で、内容確認・メタデータ修正・コメントのやり取りを行います。
- 却下済み（`rejected`）は確認リンクの「却下」操作でPDF本体が削除されています。管理画面にレコードが残って見える場合でも、PDF表示はできません。不要な登録情報だけを消す場合は「削除」を使用します。
- 管理ページは `X-Admin-Token` ヘッダーでWorker APIに認証します。トークンの共有・画面共有・ブラウザの共用には注意してください。
- ログアウトしたいときは「トークンを消去」を押します。表示中の一覧は閉じ、同じブラウザセッションでの認証情報も削除されます。
